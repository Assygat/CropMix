# Источники данных

Каждое число в `data/*.csv` со `status=real` ссылается сюда по id (колонка `source`).
Запись обязана содержать ссылку, место в документе, **точную цитату** и дату обращения.
Если источник не удалось открыть или прочитать, или нет уверенности в числе
(единицы, год, область или республика), число помечается `assumed`, а не `real`.

Формат записи (id — `S` и три цифры, по порядку):

```
## SNNN
- url: https://...
- document: название документа или таблицы
- location: страница / таблица / строка
- quote: точная цитата из источника, с единицами
- accessed: ГГГГ-ММ-ДД
- note: (необязательно) пересчёт единиц, оговорки
```

Загрузчик (`src/data_loader.py`) не пропустит число со `status=real`, если у записи
не заполнены url, location, quote или accessed.
