# Публичный сайт CropMix Twin (`web/`, 2026-11-16)

Статичный сайт из шести страниц (Decision Lab добавлена 2026-11-17): HTML, CSS и JavaScript без фреймворков и сборки. Работает с локального диска
(`file://`); рассчитан и на статический хостинг (относительные пути, без сервера), но на хостинге не проверялся. Публичный текст — на английском;
документация репозитория — на русском. Модель, данные и outputs/ сайт не меняет: расчёты остаются в Python (`src/`),
страницы показывают их результаты.

## Страницы

| Файл | Назначение |
|---|---|
| `index.html` | Главная: заставка, первый экран «Every Drop Matters» с процедурным пейзажем (по утверждённому `design-preview/`), постановка задачи, слои модели, возможности симулятора, главные результаты с диапазонами |
| `simulator.html` | Crop Allocation Simulator — интерактивная часть (`docs/simulator.md`); в общий дизайн встроены только шапка, меню и подвал |
| `planner.html` | Decision Lab (2026-11-17): планировщик для маловодного года (LP в браузере, сверен с HiGHS), стресс-тесты, эталонные результаты Python, почему экономия «той же земли» мала, экономические коэффициенты (редактируемые, пропуски не заполняются), постановка задачи. Скрипты: `data/planner.js` → `lp_solver.js` → `planner_core.js` → `planner.js`; стили — `planner.css`. Описание — `docs/decision_lab.md` |
| `methodology.html` | Методика: архитектура, переменные и единицы, ET0 (FAO-56 PM), Kc и стадии, ETc, эффективные осадки, потери, рис, региональный расчёт и Cmean, оптимизатор, базовый и оптимизированный сценарии, классы водности. Формулы — MathML. Интерактивная таблица м³/га по культурам |
| `evidence.html` | Данные и доказательства: пять видов информации, статусы по роли данных, источники, сравнение с официальными величинами, исторические структуры посевов (интерактивно), бэктест V1–V4, чувствительность, сценарии, неопределённость (Монте-Карло, 2026-11-17), проверка климата по станции (2026-11-17), ограничения |
| `about.html` | О проекте: регион и карта (границы 2017 г. и Сырдарья из данных симулятора), вопрос о воде, что модель делает и чего не умеет, для кого, что улучшило бы модель |
| `calculator-legacy.html` | Прежняя главная (калькулятор модуля 4, на русском). Не входит в навигацию; сохранена, добавлены только `meta robots noindex` и поясняющий комментарий |

Навигация одна на всех страницах: Home · Simulator · Decision Lab · Methodology · Data & Evidence · About и кнопка справа
(на симуляторе — «How it works»). Текущая страница отмечена `aria-current="page"`. До 1000 px ссылки сворачиваются
в меню (кнопка, Esc закрывает). Подвал одинаковый на всех страницах.

## Общие файлы

| Файл | Что содержит | Кто подключает |
|---|---|---|
| `site.css` | Токены, база, стекло, навигация, кнопки, подвал, reduced motion, forced colors | все шесть страниц |
| `content.css` | Секции, карточки, метки статуса, таблицы, формулы, оглавление, графики-полосы, интерактивные блоки | главная и три контентные страницы (не симулятор: у него свои `.card`, `.tag`) |
| `home.css` | Первый экран, пейзаж, заставка, диаграмма диапазонов экономии | главная |
| `simulator.css` | Карта, редактор, сравнение (без дублей `site.css`) | симулятор |
| `site.js` | Меню, подсветка за курсором, появление блоков, оглавление, заставка | все шесть страниц |
| `landscape.js` | Процедурный пейзаж (копия `design-preview/landscape.js` без изменений) | главная |
| `data_views.js` | Таблица м³/га (Methodology), исторические структуры (Evidence), карта региона (About). Формул модели нет: только `model_calc.js` (Σ площадь × коэффициент) и `sim_map.js` | Methodology, Evidence, About |

`model_calc.js` и `data/model.js` используются и симулятором, и `data_views.js`, и `calculator-legacy.html` — их нельзя
удалять. `app.js` и `style.css` нужны только `calculator-legacy.html`.

## Откуда числа

- Статичные числа на страницах взяты из outputs/, docs/ и data/SOURCES.md. Их совпадение с outputs/ проверяет
  `tests/test_site.py` (без outputs/ числовые тесты пропускаются с подсказкой выполнить `python -m src.run_all`).
- Интерактивные таблицы читают `data/model.js` и `data/simulator.js` (генерируются `src/export_web.py` и
  `src/export_simulator.py`).

## Перенос функций старого калькулятора

| Функция `calculator-legacy.html` | Где теперь |
|---|---|
| Площади любого года 2010–2025, климат года или Cmean, любой из 36 сценариев КПД | Evidence → Historical crop structures (`#history-explorer`) |
| Сравнение с лимитом 2024 и планом 2025 (×1.86, ×2.29) | Evidence → Model versus official figures и тот же блок интерактивно |
| Таблица м³/га по культурам на трёх уровнях | Methodology → Regional water use (`#coef-view`) |
| Ползунки площадей, пересчёт трёх уровней, график | Simulator (было и раньше) |
| Доход | Не показывается нигде (дохода в модели нет) |

## Запуск и проверка

- Открыть `web/index.html` двойным щелчком (сервер не нужен). Запасной вариант:
  `py -3 -m http.server 8000 --directory web` → http://localhost:8000/.
- `python -m pytest` — включает `tests/test_site.py` (структура страниц, навигация, ссылки, язык, числа = outputs/).
- Браузерные проверки (вёрстка на 1440 / 1280 / 768 / 390 px, меню, клавиатура, reduced motion, интерактивные
  таблицы, формулы, наборы симулятора) выполнялись в headless Microsoft Edge скриптами вне репозитория.
