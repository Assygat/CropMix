## Постановка (режим дефицита)

Переменные: площади x_c, га. w_c — забор «из реки», м³/га (слой 1, база КПД, Cmean). W0 = Σ w_c·x0_c = 7.30 км³.

- Σ w_c·x_c ≤ s·W0 (s — доля воды, сценарий пользователя);
- Σ x_c ≤ Σ x0_c (земля может остаться незасеянной; «same land» — равенство, как в модуле 6);
- r·x0_c ≤ x_c ≤ (1 + d)·x0_c;
- Σ_{food} x_c ≥ f·Σ_{food} x0_c;
- цель по умолчанию — максимум засеянной площади; при равенстве цели — минимум воды.

Двойственная оценка воды при цели «площадь» — 25.5 га на 1 млн м³ (= 1/39 201: предельная культура — кормовые).
В JS двойственные оценки считаются повторным решением задачи с ослаблением на 10⁻⁶ (для LP это точно, пока набор
активных ограничений не меняется). Они совпадают с маржиналами HiGHS (тест сверки, допуск 10⁻³ отн.).

## Главные результаты (модель, не факт)

**Почему экономия moderate всего 3.4 %** (`outputs/decision_attribution*.csv`):

- сокращение риса на 24 509 га освобождает 1.074 км³, но 0.827 км³ (77 %) снова тратят культуры, которые занимают его
  землю; одни кормовые забирают 0.534 км³, потому что им нужно 39 201 м³/га против 43 822 м³/га у риса;
- минимум продовольственных культур не активен: если его снять, экономия не меняется (3.38 %);
- если снять нижнюю границу риса, экономия вырастет лишь до 3.73 %: тогда начинает действовать минимум продовольственных;
- если удвоить верхние границы маловодных культур, экономия составит 7.66 %. Именно этот предел главный: эти группы малы по площади;
- если земля может пустовать, экономия составит 26.3 %, но это решение о том, сколько сеять, а не о структуре.

Вывод: 3.4 % — это свойство постановки «та же земля, коридор ±30 %», а не ошибка решателя. Сами коэффициенты
культур (кроме риса) отличаются мало: 24–39 тыс. м³/га.

**Режим дефицита** (protective; средний климат; `outputs/emergency_summary.csv`):

| Вода | Засеяно (план) | Равномерное сокращение | План − равномерное |
|---|---|---|---|
| 90 % | 93.8 % | 90 % | +7 119 га |
| 80 % | 83.9 % | 80 % | +7 294 га |
| 70 % | 74.0 % | 70 % (нарушает минимум продовольственных 80 %) | +7 469 га |
| 60 % | решения нет: нужно ≥ 4.718 км³, есть 4.383 | — | — |
| 50 % | решения нет | — | — |

Flexible выполним до 50 % (57.1 % площади). При 70 % воды (protective) площадь риса падает до 51 751 га (−36.7 %),
кормовых — до 40 197 га (−42.7 %), остальные культуры растут на +30 %. Производство риса (урожайность 5.17 т/га,
`assumed`: источники расходятся) падает с 422 тыс. до 268 тыс. т. Это компромисс «вода ↔ рис», и его видно сразу.
Без ограничения воды (сценарий normal) цель «площадь» сохраняет 100 % площади, а доводка по минимуму воды
сокращает рис до продовольственного минимума. Это видно в таблице стресс-тестов.

**Стресс-тесты** (`outputs/stress_scenarios.csv`): +2 °C → ET0 +5.5 % (1 463 против 1 387 мм за апрель–октябрь),
водозабор +5.6 %. Осадки −30 % → +0.7 %. Год-аналог засухи C2021 → +7.4 %. Комбинированный стресс
(+2 °C, −30 % осадков, 70 % воды) → дефицит 34.2 % от потребности, засеяно 69.6 % при правилах protective.

**Неопределённость** (n = 2000): W = 6.17–8.75 км³ (P5–P95), медиана 7.33; экономия moderate 2.1–5.9 %
(min 1.9 %, всегда > 0). Водозабор сильнее всего зависит от КПД каналов (ρ = −0.70), экономия — от КПД полива (0.74).

**Проверка входа** (T1–T4): NASA Tmax ниже станции на 1.59 °C (95 % ДИ −1.75…−1.45; n = 5699),
Tmin выше на 0.81 °C (по всем дням; этот вывод не подтвердился — см. поправку ниже); Hargreaves по температурам NASA на 7.9 % ниже, чем по станционным. ET0 PM/Hargreaves = 1.23
(разные методы — только контекст).

**Поправка финального аудита (2026-11-17):** 82 % станционных Tmin и 13 % Tmax в GSOD помечены флагом «*»
(экстремум выведен из срочных наблюдений; такие Tmin обычно теплее истинных). На днях с явно сообщённым
значением: Tmax −1.60 °C (n = 4984; вывод устойчив), Tmin −1.43 °C (n = 1041, в основном зима; знак обратный).
Поэтому вывод о Tmin (и об «узкой суточной амплитуде NASA») не обоснован; T3 наследует это ограничение.
Строки T1e/T2e — в `outputs/validation_climate.csv`. Границы суток не совпадают: дни GSOD — по UTC, NASA POWER — местное солнечное время (LST, ≈ UTC+4.4 ч).

## Чего нет и почему

- Экономика: нет затрат и урожайности пшеницы, кормовых и прочих зерновых, поэтому цель «стоимость» доступна только
  после ввода значений пользователем. Ничего не подставляется.
- Выход модели (забор) независимо не проверен: ряда фактического водозабора нет (n = 1, модуль 8).
- WaPOR, ERA5-Land и MOD16/GLEAM не загружены: нужны учётные записи (CDS, Earthdata), а Кызылорда, по-видимому,
  не входит в зону покрытия WaPOR (это нужно перепроверить). Код сравнения (`metrics`) для них готов.
- Отклик урожая на недополив (Ky), MILP и целевое программирование не делались. Все отношения линейны, целых решений
  не требуется, а лексикографической доводки и ε-ограничения достаточно.
